## ✨ Features | المميزات

*   **🎧 High-Quality Recitation**: Listen to the complete Holy Quran in the soul-soothing voice of **Sheikh Saad El Ghamidy**.
*   **📍 Verse-by-Verse Synchronization**: Follow along as the app automatically highlights every verse being recited in real-time.
*   **📖 Last Read / Continue**: Never lose your place! Resume your spiritual journey exactly where you left off.
*   **🔍 Smart Search**: Quickly find any Surah by its name (Arabic/English) or number.
*   **🌙 Beautiful Typography**: Features the elegant **Amiri** font for a premium, readable Mushaf experience.
*   **📱 Background Playback**: Keep listening even when the screen is off or you're using other apps.
*   **📦 Offline Ready**: Powered by **Realm** database and local assets for a fast, reliable, and data-efficient experience.

---

## 🛠️ Tech Stack | التقنيات المستخدمة

- **Framework**: [Flutter](https://flutter.dev/) (3.10+)
- **Database**: [Realm SDK](https://realm.io/) (Local NoSQL for high performance)
- **Audio Engine**: [just_audio](https://pub.dev/packages/just_audio) & [audio_service](https://pub.dev/packages/audio_service)
- **State Management**: [Provider](https://pub.dev/packages/provider)
- **Typography**: [Amiri Font](https://fonts.google.com/specimen/Amiri)

## 🚀 Getting Started

To run this project locally, ensure you have Flutter installed and set up.

1. **Clone the repository**:
   ```bash
   git clone [repository-url]
   cd saad_el_ghamidy
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Generate Realm Schemas**:
   ```bash
   dart run build_runner build
   ```

4. **Run the app**:
   ```bash
   flutter run
   ```
